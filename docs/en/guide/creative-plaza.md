# Creative Plaza

<div style="padding: 0 1em; color: #444;">

This is a curated space showcasing high-quality community resource packs. We will continuously monitor community developments and select ingenious icon packs to feature in the plaza. You may also develop traffic signs for other countries or regions based on this mod.

</div>

We apologize for any inconvenience and look forward to seeing more outstanding creations!
