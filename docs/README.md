## 模组简介

**迷上城建（Mishang Urban Construction）** 是一款专为 Fabric 平台打造的建筑与装饰类模组，旨在为玩家提供极具沉浸感和高自由度的城市建设体验。模组不仅加入了带有加速效果与自动标线功能的拟真道路、色彩丰富的自定义灯具、可灵活调节参数的告示牌以及多样化的栏杆等建筑方块，还内置了一套强大的辅助工具系统。通过其配备的快速建造、强制放置、方块旋转镜像以及 NBT 数据与状态查看等实用工具，玩家可以大幅提升搭建与调试的效率。

作为"迷上城建"生态的重要拓展，**"豹猫指示牌模组"（Ocelot Sign Mod）** 是一款同样基于 Fabric 平台开发的专业指示牌模组。该模组以道路交通指引为核心，完美继承了"迷上城建"中高度灵活的文字与图案编辑系统，旨在为玩家的城市建设提供更真实的交通细节。本模组内置了深度还原的中国大陆道路指示牌图案，并收录了大量实用的公共提示符号，新增了支持自定义编辑的专属道路指示牌方块，还提供了配套的指示牌立柱，在道路方块的基础上，特别补充了地面的"预告导向箭头"、醒目的橙色箭头以及各类禁止类箭头，进一步完善了路面交通的引导细节。结合官方提供的《图案与字体列表》（详见语雀参考文档），玩家可以精准查阅并自由调用海量图案资源。

本模组是"迷上城建"的附属模组，根据"迷上城建"的开源协议，本模组采用 **LGPL-3.0** 协议开源。模组内包含的第三方字体与前置代码修改，则分别遵循原有的 **OFL-1.1** 和 **LGPL-3.0** 协议，详情请参阅仓库 LICENSE 文件。
