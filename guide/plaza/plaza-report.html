违规内容举报

创意广场的投稿均经开发组审核后展示。若您发现资源包、模组或文章投稿中存在反动、侵权、色情或其他违法违规内容，欢迎通过邮件向我们举报。
请先阅读以下说明，以便我们更快核实与处理。

举报邮箱 ocelot.moddev@outlook.com

一、可举报的内容类型

所有投稿均依据《豹猫指示牌模组·创意广场用户投稿协议》审核后展示，但受技术与人力所限，仍可能出现疏漏。若您发现以下情况，请及时告知我们：

  1. 反动与政治敏感内容：违背相关法律法规、危害国家统一与领土完整的言论或图像。
  2. 侵权内容：未经授权使用他人的图案、模型、字体或素材，或抄袭、洗稿、未经授权转载他人文章，侵犯著作权、商标权等知识产权。
  3. 色情低俗内容：露骨、R18 或带有性暗示的图像与文字。
  4. 暴力血腥内容：惊悚、引人不适的恶俗梗或暴力画面。
  5. 恶意与欺诈内容：广告引流、诈骗链接、破坏性脚本等危害用户安全的内容。
  6. 其他违规内容：违反中国大陆法律法规或《豹猫指示牌模组·创意广场用户投稿协议》的其他信息。

二、举报方式

  1. 请使用下方邮件模板，将举报信息发送至 ocelot.moddev@outlook.com。
  2. 邮件主题统一为“【举报】+ 被举报资源名称或文章标题”。
  3. 请写明页面链接、资源包名称或文章标题，以便我们准确定位被举报内容。
  4. 请简要说明问题类型与具体位置，如有截图或录屏证据请一并附上。
  5. 如需了解处理结果，可在邮件中留下常用邮箱；我们不会公开举报人信息。

三、举报邮件模板

可直接复制以下格式填写，内容越具体，核实效率越高。

收件人：ocelot.moddev@outlook.com

主题：【举报】[被举报资源名称或文章标题]

被举报内容： ______________________________（页面链接、资源包名称或文章标题）
问题类型： __________________（反动 / 侵权 / 色情 / 暴力 / 诈骗 / 其他）
问题说明： ______________________________（具体位置与情况描述）
附件： ________________________（截图或录屏，可选）

提示：若您是权利人或其代理人，请附上权属证明，以便我们加快处理。

四、处理流程与说明

  1. 收到举报后，开发组将尽快核实。
  2. 核实属实的内容会立即下架，并视情节决定是否拒绝该作者的后续投稿。
  3. 存在争议的内容可能先行隐藏，待补充说明后再作判定。
  4. 证据不足、重复提交或明显恶意的举报，我们将不予处理。
  5. 若您在邮件中留下联系方式，处理结果将通过邮件反馈。

感谢您帮助我们维护创意广场的内容环境！
