告示牌基本使用方法 | 迷上城建

本模组添加了多种纹理的告示牌方块。

一、告示牌分类

《迷上城建》模组中的告示牌主要分为以下三种类型：

1. 悬挂的告示牌

  1. 此类告示牌应悬挂在方块下方，两侧均可输入文字。如果上方连接固体方块或告示牌杆方块，则会显示告示牌杆。
  2. 告示牌的文字与放置方向绑定，暂不支持直接旋转。如果你需要放置带有 NBT 的方块，则需确保放置方向与获取方向一致，否则相应侧面将不显示文字。例如，如果你获取了朝南/北的告示牌，若放置为朝东/西，原有的南北侧文字将无法显示。

2. 墙上的告示牌

  1. 此类告示牌可放置在任何方块的任意表面（侧面、顶面、底面），只有一面可输入文字。
  2. 墙上告示牌有两个特殊变种：隐形告示牌与隐形发光告示牌。这两种告示牌的模型不可见，只有文字可见。当玩家手持任一类型时，已放置的隐形告示牌会显示轮廓，便于识别。

3. 立式告示牌

  1. 放置于地面或悬浮在空中，支持原版的 16 个方向。与悬挂告示牌一样，两侧均可输入文字。
  2. 当方块放置在下方时，会显示告示牌杆。空手时，按住 Shift 并点击告示牌可手动切换杆的可见性。

二、基础文字编辑

玩家右键点击告示牌时，会打开编辑界面（悬挂/立式告示牌需点击对应侧面）。告示牌支持多行文字，每行可独立配置以下属性：

1. 基础样式

粗体、斜体、下划线、删除线、随机字符等。

2. 文字大小

默认值：6。全尺寸告示牌（包括两种隐形变种）默认值为 8。

3. 偏移（X/Y/Z）

沿三个轴调整文字偏移。

⚠️ 请谨慎调整 Z 轴，否则可能导致文字漂浮于平面之外或被告示牌遮挡而不可见。

4. 缩放（X/Y）

与文字大小叠加。将缩放设置为 0 将隐藏文字。

无 Z 轴缩放，因为在二维平面上没有意义。

5. 旋转

支持围绕 X、Y、Z 轴旋转。

6. 对齐

支持水平对齐与垂直对齐。

7. 颜色与描边

  • 文字颜色：内置 16 色 / 自定义颜色。
  • 描边颜色：禁用、自动匹配文字颜色（原版发光行为）、内置颜色、内置颜色的发光变体 / 自定义颜色。

8. 阴影

⚠️ 不推荐开启。多方向文字开启阴影可能导致渲染顺序问题。

9. 绝对模式

启用后，该行将在"重新排列"功能中被忽略。

三、高级排版与编辑功能

1. 按钮与数值调节

基础操作

  • 左键单击：调节
  • 右键 / Shift + 左键：反向调节
  • 鼠标中键 / Alt + Shift + 左键：重置为默认值

也可直接使用鼠标滚轮滚动调节。

速度倍率

  • 按住 Ctrl 为 ×8 倍速
  • 按住 Alt 为 1/8 倍速

自定义数值输入

点击"设置自定义值"后点击目标按钮，或按 Tab 聚焦后按 Ctrl+E 输入数值。

颜色支持：颜色名称（如 red）或十六进制（#rgb、#rgba、#rrggbb、#rrggbbaa）。描边可输入 none（禁用）或 auto（自动）。

2. 文字布局与多选

自动布局

点击"调整位置"按钮，可根据文字大小自上而下排列各行（行间距 1/8，绝对模式的行除外）。不同的垂直对齐方式独立计算。

多选

按住 Ctrl 或 Shift 可选择多行进行批量设置或输入。按钮的增量会相对应用；自定义值或默认值会统一应用到所有选中行。

跨方块溢出

文字在告示牌区域之外仍然可见。若要在两个单方块告示牌之间居中显示文字，请在左侧告示牌上输入文字，设置为居中对齐，并向右偏移 8 个单位。

3. 背面复制与翻转

从背面复制

悬挂/立式告示牌可直接从对面复制文字。复制过程中，X 偏移、水平对齐与文字内箭头（如 →）会自动反向，适合制作双面告示牌。

翻转

选择单行后点击"翻转"按钮，可反转其 X 偏移、对齐与箭头。按住 Ctrl 并点击"翻转"可应用到所有行。

4. 渲染说明

Z-Fighting

半透明文字 + 粗体 / 半透明描边时容易出现。

不透明度行为

当描边颜色设置为"自动"时，其不透明度跟随文字变化。若选择特定颜色，则不受文字不透明度影响。

透明遮挡

半透明文字可能遮挡其后方的半透明内容（彩色玻璃、水、云）的渲染。

四、键盘快捷键（1.19.4+）

1. 焦点导航

Tab 在文字区域与按钮区域之间切换；方向键在按钮/文字行之间导航。

示例：按 Tab 选中"粗体"，按 Enter 切换；按 → 选中"斜体"，再按 Enter 切换。

2. 快速样式

快捷键 动作
Ctrl + I 斜体
Ctrl + S 删除线
Ctrl + U 下划线
Ctrl + O 随机字符

注意：Ctrl+B 与屏幕阅读器快捷键冲突，因此不用于切换粗体。

3. 行操作

动作 快捷键
新建一行 Ctrl + Shift + = 或 Ctrl + Numpad+
删除一行 Ctrl + - 或 Ctrl + Numpad-
移动行 Ctrl + Shift + ↑/↓

五、特殊格式指令

在文字行中输入以下特殊指令以插入自定义内容：

1. 数据组件与图形

  • -json <代码>：自定义 JSON 文本（宽松模式，键与值的引号可省略）。
    • 示例：-json {text:Some Text, color:red, bold:true}
  • -nbt <组件>：使用 NBT 设置文本（仅 1.21.5+）。
  • -rect <宽度> <高度>：绘制指定大小的矩形（受文字大小与缩放影响）。
  • -texture <路径>：显示一张贴图（依赖资源包，不支持在线图片）。建议使用 -nbt {sprite: 'block/lava_still'} 以获得更好的稳定性与动画贴图支持。

六、物品交互功能

1. 上蜡与去蜡（蜜脾）

对告示牌使用蜜脾可上蜡，锁定编辑与发光状态。

在创造模式下可使用蜜脾去蜡（生存模式不可）。

2. 发光效果（发光墨囊 / 墨囊）

  • 发光墨囊：让文字发光（在黑暗中亮度最高，对描边或方块亮度无影响）。
  • 墨囊：移除文字发光效果。

对于悬挂和立式告示牌，上蜡与发光操作在两侧独立应用。在非创造模式下，每次成功上蜡/发光都会消耗对应物品。
